# 💼 Sprint 5 - Portfolio

In this sprint, the goal was to develop a personal portfolio, highlighting skills, projects, and individual style.

## 🚀 Technologies Used

- **React**
- **TypeScript**

## 🎨 Part 1 - Visual Planning

The project started with a layout created in **Figma**, which served as a guide for structuring ideas and visual identity.

## 💡 Inspirations and Features

- Dynamic display of the **technologies used** in the projects
- Integration with **social media**
- Showcasing of **developed projects** in an attractive and organized layout
- **"About Me"** section, sharing a bit of personal background

## 🎨 Color Palette and Images

- Careful selection of colors to represent the visual identity

## ☁️ Hosting

The portfolio was deployed using the **Vercel** platform, providing fast and public access.
